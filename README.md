# RAG-платформа для работы с документами  

Сервис, который позволяет загружать документы, искать в них по смыслу (семантический поиск) 
и получать ответы на вопросы с цитированием источников.

## 🎯 Основные задачи
Проект демонстрирует навыки работы с LLM, векторными базами и асинхронной обработкой данных.

## 🛠 Стек технологий
*   **Core:**  
`Python 3.12+` — основной язык разработки.  
`FastAPI` — асинхронный веб-фреймворк для API-эндпоинтов.  
`PostgreSQL + pgvector` — реляционная база данных с векторным расширением для хранения эмбеддингов и метаданных.  
`SQLAlchemy 2.0 (async)` — асинхронный ORM для работы с базой данных.  
`Celery + Redis` — фоновая обработка задач (индексация документов, векторизация) и брокер сообщений.  
*   **AI & Embeddings:**  
`sentence-transformers` — генерация эмбеддингов локально (или альтернативно OpenAI API).  
`LangChain / LlamaIndex` — оркестрация RAG-пайплайнов (чейнинг, промпты, ретривер).  
`OpenAI API / Anthropic API` — LLM для генерации ответов (закрытые модели).  
*   **Quality Assurance (QA):**  
`pytest` — написание и запуск модульных и интеграционных тестов.  
*   **DevOps & Tools:**  
`Poetry / uv` — управление зависимостями и виртуальным окружением.  
`Docker` — контейнеризация  

## ⚙️ инструкции по установке и использованию разработанных функций
1. Клонируйте репозиторий:  
```
git clone https://github.com/4usnok/deep_search.git
```
2. Установите зависимости:  
```
poetry install  
```
